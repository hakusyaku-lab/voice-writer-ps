# voice-writer（音声原稿）PowerShell版

Windows標準の日本語音声認識で話した内容を文字起こしし、AIで読みやすく整えた「改善版」も作れるデスクトップアプリです。インストール不要で、PowerShellだけで動きます。

## できること

- **ファイル1：文字起こし**　マイクボタンで話すと、そのまま文字になります（オフラインで動作）。
- **ファイル2：改善版**　ファイル1をAIで誤変換・言い淀み・句読点を整えた版にします（APIの導入が必要）。
- **ファイル1／2の切り替え**　画面上のボタンで表示を切り替え、どちらも直接編集できます。
- **発言者の表示**　「発言者」欄で話者を選ぶと、話者が替わったところに `[12:45] 話者A：` のように付きます。`F2` で切り替え、名前の直接入力もできます。
- 「改行」「句点」「読点」と話すと、改行・。・、が入ります。
- すべて自動保存されます。

> 声から自動で話者を見分ける機能はありません。話す人が替わったら手動で切り替えてください。

## 動作環境

- Windows 10 / 11
- Windows PowerShell 5.1（Windowsに標準搭載）
- 日本語の音声認識（日本語版Windowsなら通常は入っています）
- マイク

## 使い方

1. このリポジトリをダウンロード（Code → Download ZIP）して展開します。
2. `start.bat` をダブルクリックします。
3. 🎤ボタンで聞き取り開始、もう一度押すと停止します。

保存先は `ドキュメント\音声原稿\` です。

| ファイル | 中身 |
| --- | --- |
| `ファイル1_文字起こし.txt` | 文字起こしの結果 |
| `ファイル2_改善版.txt` | AIで整えた改善版 |
| `config.json` | APIキーなどの設定（初回起動時に作成） |

## ファイル2：改善版（APIの導入が必要です）

ファイル2を作るには、OpenAIのAPIキーを導入してください。APIの利用料金は各自の負担です。

1. [OpenAIのAPIキーのページ](https://platform.openai.com/api-keys)でAPIキーを作成します。
2. 次のどちらかの方法で設定します。
   - `ドキュメント\音声原稿\config.json` をメモ帳で開き、`"openai_api_key": ""` の `""` の中に貼り付けて保存する（書き方は `config.example.json` を参照）
   - 環境変数 `OPENAI_API_KEY` に設定する
3. アプリの「改善版を作る」ボタンを押します。

`model` を書き換えると、使うモデルを変えられます（初期値は `gpt-4o-mini`）。

> **APIキーは絶対にGitHubに上げないでください。** `config.json` は `.gitignore` で除外しています。

## ブラウザ版

`web/voice-writer.html` は、Chromeの音声認識を使うブラウザ版です。Chromeで開いてマイクを許可すると使えます。
